01 / MODEL MECHANICS

让 Attention
从矩阵变成直觉。

选择当前 Query，调整温度与因果掩码。左侧变量每次改变，右侧分数、概率和热力图都会重新计算。

QKᵀ / √dCausal maskSoftmax

实验控制台

使用固定的 5 个二维教学向量，专注观察机制。

score(i,j) = qᵢ · kⱼ / √2
weight(i,j) = softmax(score(i,j) / τ + mask)
本页的 Q/K 是教学向量，不代表模型真实权重或自然语言语义。

同一 Query：因果掩码 vs 无掩码

两个结果都用当前温度计算。切换上方模式不改变这组对照。

读图时留意

  1. 掩码把未来分数设为 −∞，Softmax 后严格为零。
  2. 降低温度只改变可见 Key 之间的相对概率。
  3. 概率总和为 1；“关注更多”不能仅凭某个最大权重判断。
DEEP DIVE / 变量与验证

从分数到概率

先读变量，再按照下面的步骤改变一个控制量，观察右侧指标。

变量含义在本页如何使用
qᵢ / kⱼ第 i 个查询 / 第 j 个键固定二维教学向量；分数由点积给出
√d键向量维度缩放此页 d=2，防止点积随维度增加而过大
τ教学温度先把分数除以 τ，再做 softmax
mask可见性约束因果模式将未来位置排除在归一化之外

三步实验

  1. 把 Query 移到第 2 个 token，切换因果掩码：未来三列的概率应变为零。
  2. 保持 Query 不变，只调低 τ：最高分对应的位置更集中；排序不应改变。
  3. 看熵与“可见 Key 数”：前者是分布集中程度，后者是掩码约束，两者不是同一指标。
模型边界：这里没有训练 Q/K，也没有 V 与多头投影；热力图只演示 QKᵀ、掩码和 softmax。

参考：Vaswani et al., Attention Is All You Need。温度 τ 是本实验额外加入的教学控制量。
