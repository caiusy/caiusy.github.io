03 / ALIGNMENT

RLHF：从人类偏好到策略更新。

先比较两个回答，理解奖励模型怎样学习偏好；再计算优势，亲手运行 PPO 与 KL 约束下的策略更新。每一步都有公式、数值和适用边界。

00 / VARIABLE MAP

先认清每个变量的职责

符号是什么本页怎么算是否被训练
y⁺ / y⁻被偏好 / 未被偏好的回答由你的选择决定数据标签
s_A / s_B奖励模型给两个回答的分数滑杆设定的玩具分数真实训练中由奖励模型学习
P_pref模型预测你选 A 的概率σ(s_A−s_B)由分数计算
R / V / A选中回答的奖励 / 价值基线 / 优势本页用 A=R−V此处都是教学量
π_old / π_new采样时 / 更新后的策略二选一动作概率只更新 π_new
π_ref冻结的参考策略二选一参考概率冻结
r / ε / β概率比 / PPO 裁剪宽度 / KL 系数r=π_new/π_old本页配置量

关键区分：π_old 用于 PPO 的概率比，π_ref 用于约束策略偏移；两者的作用不同。下方只有两个候选动作，真实语言模型拥有完整词表和长序列。

01 / PREFERENCE DATA

先做人类偏好比较

同一个问题有两个回答。选出你更喜欢的，再拖动奖励模型分数，观察“模型是否理解你的偏好”。

示例提示 / PROMPT为什么长文本生成通常需要 KV Cache？

奖励模型的两个分数

P(A ≻ B) = σ(s_A − s_B)
偏好损失 = −log P(被选中的回答)

偏好学习账本

—模型预测所选回答的概率
—偏好交叉熵损失

分数只表示相对偏好：给 s_A、s_B 同时加同一个常数，偏好概率不变。这里滑杆代替训练奖励模型。

02 / REWARD TO ADVANTAGE

奖励高，不等于优势一定为正

优势比较“实际得到的奖励”与“基线原本预期的奖励”。这里用最简单的 A=R−V 演示符号；实际 PPO 通常使用按时间步估计的优势。

R = 奖励模型对选中回答的分数
A_demo = R − V
—选中回答的奖励 R
—教学优势 A_demo

本页把回答级分数直接当作奖励，并省略序列内每步奖励、价值函数训练及 GAE。按钮只是把这个示意值带入下方 PPO 控制台。

PPO 控制台

把一次 response 中的一个二选一动作抽出，观察策略更新。可以接收上方算出的教学优势。

J_demo = min(rₜAₜ, clip(rₜ,1−ε,1+ε)Aₜ) − β·KL
π_new = rₜ·π_old；KL = D(π_new ‖ π_ref)

当前 PPO 目标如何计算？

两个候选项取较小者，再减去二选一动作分布相对于参考策略的精确 KL。目标值与梯度方向要分开读。

05 / 复盘与边界

再回看 PPO 的关键量

先读变量，再按照下面的步骤改变一个控制量，观察右侧指标。

变量含义在本页如何使用
Aₜ动作相对基线的优势正值倾向增加动作概率，负值倾向降低
rₜ新策略与旧策略概率比rₜ = π_new(a|s) / π_old(a|s)
εPPO 裁剪区间半宽区间 [1−ε, 1+ε]
β参考策略偏离惩罚系数此页使用二选一动作的精确 KL

三步实验

  1. 先令 Aₜ 为正，增大 rₜ 超过 1+ε：观察 clipped surrogate 的上界。
  2. 将 Aₜ 改为负，再把 rₜ 降到 1−ε 以下：裁剪生效的方向会反过来。
  3. 调大 β：最终 surrogate 数值下降；它不是完整训练梯度。
模型边界：完整 RLHF 的偏好数据、奖励模型、价值函数、序列奖励与批量优化未在此页运行。单 token surrogate 的数值不能直接当作“模型变好”的证据。

参考：PPO 原论文、InstructGPT（RLHF）。 说明：偏好、奖励和训练轨迹均为教学示例；PPO 部分使用二选一动作模拟。KL 在本页对二选一动作分布精确计算；完整 RLHF 还涉及 batch、GAE、value loss、词表概率和序列级奖励。
