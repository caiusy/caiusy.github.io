02 / LIVE TRAINING

亲手跑一个 2×2 LoRA

这是真正按梯度公式计算的玩具训练。目标矩阵 T 与冻结 W 的差是 rank 1，因此 r=1 已能表达目标；改成 r=2 可以比较参数路径。示例与上方的大矩阵估算互相独立。

训练控制

目标：T = [[1.6, −0.3], [0.4, 0.8]]
冻结：W = [[1, 0], [0, 1]]
Loss = ½‖W + (α/r)BA − T‖²_F
每步：A,B ← A,B − η·∇Loss，η = 0.08

输入取两个标准基向量，相当于观察这 2×2 线性层在两种输入上的输出。曲线是此玩具目标的训练误差，不能推断真实模型质量。

03 / SCALE ESTIMATOR

输入一组线性层尺寸，比较全量训练与只训练 LoRA A、B 的参数规模。数字只覆盖所选线性权重，不代表整模型总参数或训练峰值显存。

04 / ENGINEERING NOTES

把图上的结论带回实际微调

01 / TARGET MODULES

先决定放在哪里

选择 Q、K、V、O 或前馈投影，会改变覆盖的权重与任务表达能力。目标矩阵数量本身不能说明模型效果；先记录基线和目标模块。

02 / RANK & SCALE

rank 是容量，不是保证

r 越大，参数开销线性增加；收益取决于任务、数据和目标层。α/r 改变更新幅度，需与学习率一起实验，而不是单独追求更大。

03 / DEPLOYMENT

推理时可选择合并

对普通线性层，固定适配器可把 (α/r)BA 合进 W。多适配器切换或量化部署要核对具体实现及精度；训练中通常保留分支。

建议按这三步动手

  1. 先看初始 ΔW=0，再点击“训练 1 步”，观察 B 先被更新。
  2. 比较玩具 r=1 与 r=2 的曲线；本目标本来就是 rank 1，增大 r 不等于必然更好。
  3. 把大矩阵 rank 从 8 调到 64，观察可训练参数与冻结权重占用各怎样变化。

理论依据：Hu et al., LoRA: Low-Rank Adaptation of Large Language Models。本页 2×2 数值由浏览器按所列公式计算，属于教学示例；规模估算采用明确列出的简化口径。
