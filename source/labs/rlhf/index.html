DEEP DIVE / 变量与验证

从人类偏好到策略更新

先读变量，再按照下面的步骤改变一个控制量，观察右侧指标。

变量含义在本页如何使用
Aₜ动作相对基线的优势正值倾向增加动作概率，负值倾向降低
rₜ新策略与旧策略概率比rₜ = π_new(a|s) / π_old(a|s)
εPPO 裁剪区间半宽区间 [1−ε, 1+ε]
β参考策略偏离惩罚系数此页搭配教学用 D_proxy

三步实验

  1. 先令 Aₜ 为正，增大 rₜ 超过 1+ε：观察 clipped surrogate 的上界。
  2. 将 Aₜ 改为负，再把 rₜ 降到 1−ε 以下：裁剪生效的方向会反过来。
  3. 调大 β：最终 surrogate 数值下降；它不是完整训练梯度。
模型边界：完整 RLHF 的偏好数据、奖励模型、价值函数、序列奖励与批量优化未在此页运行。单 token surrogate 的数值不能直接当作“模型变好”的证据。

参考：PPO 原论文、InstructGPT（RLHF）。 说明：这是单 token 的 PPO surrogate 教学模拟。D_proxy = ½(log rₜ)² 仅用于演示参考策略偏移，并非真实 KL 散度；完整 RLHF 还涉及 batch、GAE、value loss 和序列级 KL。
