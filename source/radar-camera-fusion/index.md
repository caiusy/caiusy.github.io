## 1. 基础问题

**为什么需要雷视融合**
- 雷达：测距、测速准，但目标语义贫乏，分辨率粗
- 相机：语义、形状、类别全，但深度模糊、雨雾失效
- 互补之处恰好覆盖各自短板

**路侧场景 vs 车端场景**
- 路侧：相机高、视野远、目标小，雷达点稀疏但 ROI 固定
- 车端：相机低、视野近、目标大，雷达点密集但 ROI 随车移动
- 标定方式、评测指标、关注的失败模式都不同

## 2. 标定问题

**核心变换**
- 雷达 → 图像（带深度、不带深度）
- 雷达 → BEV
- 图像 → BEV（地面假设）
- 单应性矩阵 H 的几何含义
- 外参（R, t）的最小参数化

**常见做法**
- 标志物对位（角反射器 + 标定板）
- 自标定（基于运动 / 一致性约束）
- 半自动（人工选点 + 自动求解）

## 3. 匹配问题

雷达目标和图像目标怎么"配对"。

**匹配类型**
- 点 ↔ 点（雷达点 ↔ 像素点）
- 框 ↔ 点（图像 bbox ↔ 雷达 cluster）
- 轨迹 ↔ 轨迹（关联跟踪结果）

**距离度量**
- 距离门限（gate）
- IoU（投影到同一空间后）
- center distance
- velocity consistency
- 类别一致性

## 4. 评测问题

融合系统怎么算"做好了"。

**评测维度**
- 检测区域（有效区 vs 盲区）
- 漏检（雷达漏 / 相机漏 / 联合漏）
- 虚警（雷达虚 / 相机虚 / 联合虚）
- 距离误差（横向 / 纵向）
- 速度误差
- 角度误差
- 轨迹连续性（ID switch / fragmentation）

**评测的工程化**
- 评测集：固定路口 + 多种天气
- 真值：人工标注 + 高精度 LiDAR 辅助
- 报告：按距离段、按目标类别分桶
